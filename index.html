04 / ANVIL-MOPD

A targeted lesson.
A standalone student.

First-decisive-fault routing selects a specialist and correction span. Stage-balanced reference learning supervises active stages, while span-normalized distillation focuses correction. The standalone 9B student can return auxiliary verification signals under evidence-backed acceptance.

01 / ROLLOUT

Find the first decisive fault

The student attempts active stages. Shared references distinguish a correct, incorrect or uncertain response.

02 / TRANSFER

Select the teacher and span

Stage-balanced reference learning and span-normalized distillation retain each native output's structure.

03 / RETURN

Assist the next verification round

The generalist flags inconsistencies; independent evidence retains acceptance authority. Held-out targets stay outside the loop.

Placement and routing: protocols & limitations

Source coverage, not extra updates alone

Vacancy + replay reaches 68.00 / 66.71 on Where2Place, compared with replay-only 38.00 / 36.22 (seeds 43/44). All arms use 303 updates and 7,264 row exposures. Unique images and token counts are not matched. Some reasoning and general-retention scores decrease.

Route a decisive error

Weighted semantic routing reaches 71.81% strict G→S success vs. 70.21% for flat distillation on 282 images across 50 scenes, averaged over seeds 17/23. The difference's 95% scene interval is [0.41, 2.80] points. It ties declared routing; uniform semantic routing reaches 72.34%.
